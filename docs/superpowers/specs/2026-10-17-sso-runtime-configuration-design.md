# SSO 运行时配置设计

## 背景

SparkOps 已具备 OIDC、LDAP 登录链路以及登录页展示策略，但提供商连接参数只能通过后端 `config.yaml` 配置。平台设置页只能查看运行状态并控制登录页展示，无法完成提供商配置、连接验证和运行时启停。

本设计为超级管理员提供完整的 SSO 配置能力，并确保敏感信息不经由通用系统配置接口暴露。

## 目标

- 在平台设置页配置 OIDC 和 LDAP。
- OIDC 与 LDAP 可以同时配置和启用，登录页按默认提供商展示。
- 启用提供商前必须通过连接测试。
- 保存后立即生效，不重启后端。
- 敏感字段加密存储且永不通过读取接口返回。
- 配置更新失败时继续使用上一份有效运行时配置。
- 保留 `config.yaml` 作为未建立数据库配置时的初始化兼容来源。

## 非目标

- 不实现 SAML、CAS 或其他认证协议。
- 不实现租户级或工作区级 SSO 配置。
- 不改变外部身份自动创建、绑定和 Token 签发规则。
- 不在本阶段实现 OIDC RP-Initiated Logout 或 LDAP 用户目录同步。

## 架构

### 配置边界

新增独立的 SSO 配置存储和管理接口，不把连接密钥写入现有 `platform_admin.sys_cfg`。现有 `sys_cfg.sso` 继续只保存登录页展示策略：

- 是否展示企业 SSO。
- 默认展示提供商。
- 是否允许邮箱密码登录。

连接配置由 identity 模块管理，只有超级管理员接口可读写。

### 持久化模型

新增 `identity.sso_configs` 表，每个提供商一行：

- `provider`：`oidc` 或 `ldap`，唯一。
- `enabled`：是否在运行时启用。
- `config`：非敏感配置 JSON。
- `secret_blob`：AES-GCM 加密后的敏感配置 JSON。
- `tested_fingerprint`：最后一次测试成功的配置指纹。
- `tested_at`：最后一次测试成功时间。
- `version`：配置版本，用于并发控制和多实例刷新。
- 标准创建、更新时间字段。

OIDC 的 `client_secret` 与 LDAP 的 `bind_password` 进入 `secret_blob`。加密复用 `platform/crypto.SecretBox`，生产环境优先使用 `security.secret_encryption_key`。

读取接口只返回 `has_client_secret` 和 `has_bind_password`，不返回明文或密文。更新时空值表示保留现有密钥，显式 `clear_*` 才清除。

### 运行时管理器

identity 模块新增线程安全的 SSO 运行时管理器：

- 启动时优先加载数据库配置；数据库没有配置时使用 `config.yaml`。
- 将已验证配置构造为不可变的 OIDC/LDAP 客户端快照。
- 保存成功后原子替换快照，新请求立即使用新配置。
- 构造、验证或保存失败时不替换快照。
- 多实例通过配置 `version` 周期检查刷新；当前实例保存后立即刷新。

登录和公开 providers 接口从管理器读取当前快照，不再持有启动时固定客户端。

## API

所有管理接口位于 `/api/v1/admin/sso`，要求登录且具备超级管理员权限。

### 读取配置

`GET /api/v1/admin/sso`

返回登录策略、OIDC/LDAP 非敏感字段、密钥存在标记、测试状态和运行状态。

### 测试提供商

`POST /api/v1/admin/sso/test`

请求包含提供商和当前草稿。服务端合并已保存但未重新输入的密钥，规范化配置并执行连接测试。成功时返回测试指纹和简要结果；失败时返回可操作的错误信息，不记录密钥。

OIDC 测试：

- 根据 Issuer 获取 `/.well-known/openid-configuration`。
- 校验 issuer、authorization、token、userinfo 端点。
- 支持高级端点覆盖。
- 校验 Client ID 和 Client Secret 是否满足配置要求，但不声称已验证密钥真伪；标准授权码模式只有在真实用户回调换取 Token 时才能最终验证客户端凭据。
- 不发起需要真实用户交互的授权码登录。

LDAP 测试：

- 建立连接并执行 TLS/连接超时约束。
- 使用 Bind DN 和 Bind Password 完成服务账号绑定。
- 校验搜索 Base、Filter 及属性名格式。
- 不要求输入最终用户密码。

### 保存配置

`PUT /api/v1/admin/sso`

服务端完成字段校验、密钥合并、测试指纹校验、锁死状态检查、加密持久化和运行时热更新。响应返回脱敏后的最新配置。

启用规则：

- 启用的提供商必须具有与当前规范化配置一致的成功测试指纹。OIDC 的成功测试表示 Discovery、端点和字段有效，不等同于完成真实身份提供商登录。
- 关键连接字段变化会使测试指纹失效。
- 若关闭密码登录且展示 SSO，则至少有一个已测试并启用的提供商。
- 默认提供商必须处于启用状态；否则自动选择另一个已启用提供商或拒绝保存。

## OIDC 配置

基础字段：

- `enabled`
- `issuer`
- `client_id`
- `client_secret`
- `redirect_url`
- `scopes`，默认 `openid email profile`

高级覆盖：

- `authorization_endpoint`
- `token_endpoint`
- `userinfo_endpoint`

默认使用标准 Discovery。高级覆盖只替换对应端点，Discovery 仍用于校验 issuer 和缺失端点。

## LDAP 配置

- `enabled`
- `url`
- `bind_dn`
- `bind_password`
- `user_search_base`
- `user_search_filter`，默认 `(uid=%s)`
- `email_attribute`，默认 `mail`
- `name_attribute`，默认 `cn`

LDAP URL 支持 `ldap://` 和 `ldaps://`。连接、搜索和绑定均设置超时，错误响应不区分账号存在性。

## 前端设计

平台设置页的 SSO 标签分为三个清晰区块：

1. 登录策略：展示企业 SSO、默认提供商、允许邮箱密码登录。
2. OIDC：运行状态、启用开关、基础字段、可折叠高级端点覆盖、测试连接。
3. LDAP：运行状态、启用开关、连接和搜索字段、测试连接。

交互规则：

- 页面只设置一个主操作“保存 SSO 配置”。
- 每个提供商有次级“测试连接”操作和独立测试状态。
- 修改关键字段后立即将该提供商标记为“需要重新测试”。
- 密钥输入显示“已配置”；留空保留，显式操作才替换或清除。
- 测试和保存期间禁用冲突操作，并提供成功、失败及下一步建议。
- 加载、错误和正常状态分离，使用现有组件和设计 Token。

## 数据流与失败处理

保存流程：

1. 前端提交草稿以及最近测试指纹。
2. 后端鉴权并规范化字段。
3. 合并保留的加密密钥。
4. 校验启用提供商的测试指纹。
5. 校验防锁死规则。
6. 在事务中加密并写入配置。
7. 构造新的运行时快照。
8. 原子替换当前快照并返回脱敏配置。

若第 7 步失败，事务不提交；旧快照继续服务。外部服务临时不可用不会自动停用已运行配置，但会在管理页显示最近测试时间和当前加载状态。

## 安全与审计

- 管理接口仅超级管理员可访问。
- 密钥不出现在 GET 响应、错误详情、日志和操作记录中。
- 操作日志记录提供商、动作、结果和配置版本，不记录完整请求体。
- API 对外部连接设置超时，限制响应体大小，并拒绝明显非法 URL。
- 回调 `state` 保持一次性消费；OIDC Discovery 和端点仅允许 HTTP/HTTPS，生产配置建议强制 HTTPS。
- 配置写入采用乐观版本控制，防止多个管理员互相覆盖。

## 测试

后端单元与集成测试覆盖：

- 非敏感配置与密钥加密、解密、保留、替换和清除。
- GET 响应不泄露明文或密文。
- OIDC Discovery、端点覆盖、连接失败和超时。
- LDAP Bind 成功、失败、超时和搜索配置校验。
- 测试指纹失效及未测试配置禁止启用。
- 防锁死规则和默认提供商校验。
- 保存失败不替换运行时快照。
- 保存成功后登录接口立即读取新快照。
- 超级管理员权限与未授权访问。

前端测试覆盖：

- 初始加载与脱敏密钥状态。
- 修改关键字段后测试状态失效。
- 测试通过前不能启用。
- 空密钥保留以及显式替换、清除。
- OIDC 高级字段折叠与 LDAP 字段校验。
- 保存成功、服务端错误及并发版本冲突展示。

## 兼容与迁移

- 自动迁移创建 `identity.sso_configs`。
- 表为空时从当前 `config.yaml` 构造运行时配置，但不自动把密钥写入数据库。
- 管理员首次保存后，数据库配置成为唯一运行来源。
- 现有登录页策略和外部身份数据无需迁移。

## 验收标准

- 超级管理员可在前端完整配置、测试并启用 OIDC/LDAP。
- 两种提供商可同时启用，登录页按默认提供商展示。
- 测试未通过或配置变化后不能启用对应提供商。
- 保存后新登录请求立即使用新配置，无需重启。
- 数据库、API、日志和前端均不暴露明文密钥。
- 错误更新不会中断上一份有效 SSO 登录配置。

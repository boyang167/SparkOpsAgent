# 登录页左侧品牌区重设计

## 目标

将当前深色、卡片堆叠的品牌区改为克制的浅色产品叙事区，使登录页更轻、更现代，同时保持登录表单为页面唯一操作焦点。

## 视觉方向

- 左右两侧使用相近的暖白与浅灰表面，通过空间而非强色块区分。
- 全局只使用现有中性色设计 Token，不使用渐变、彩色光晕和装饰阴影。
- 左侧约占桌面宽度的 55%，右侧保持居中登录卡片。
- 品牌标识位于左上方；主体内容垂直居中；信任信息位于底部。

## 内容结构

1. 品牌标识：SparkOps 图形标识与名称。
2. 核心标题：构建、交付、治理企业级 Agent。
3. 简短说明：强调统一控制台、私有化部署和组织治理。
4. 产品流程预览：使用原生 HTML/CSS 呈现“构建 → 发布 → 运行 → 观测”四阶段，不依赖图片或新 UI 库。
5. 底部信任信息：私有化部署、企业身份接入、审计治理。

## 交互与响应式

- 流程节点仅提供轻微 hover 背景变化，不承担导航功能。
- 动效限制在 180ms 以内，并遵循 reduced-motion 设置。
- 小于 960px 时隐藏左侧品牌区，保留移动端品牌标识与登录表单。
- 不改变登录、注册、SSO 或认证数据流。

## 实现范围

- 修改 `fronted/apps/web/app/(auth)/layout.tsx` 的左侧内容结构。
- 重写 `fronted/apps/web/app/globals.css` 中现有 `.auth-brand*` 样式。
- 保留 `.auth-shell`、`.auth-panel`、登录卡片和表单接口，避免影响认证逻辑。

## 验收标准

- 桌面端无深色大面积背景、渐变光晕和功能卡片堆叠。
- 登录按钮仍是全屏唯一高对比操作。
- 左侧在 960px 以下隐藏，登录流程可正常使用。
- CSS 可由 Next.js/PostCSS 正常解析，前端类型检查和构建不新增错误。
